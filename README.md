# Sea To University
เส้นทางจากทะเล สู่มหาวิทยาลัย

แอปวางแผนอ่านหนังสือสำหรับนักเรียน ม.ต้น และ ม.ปลาย เลือกระดับชั้นตอนเปิดแอปครั้งแรก
- **ม.ต้น:** จัดตารางอ่านสอบในโรงเรียน + เตรียมสอบเข้า ม.4
- **ม.ปลาย:** จัดตารางอ่านสอบในโรงเรียน + เตรียม TCAS (TGAT · TPAT · A-Level)

ทำอะไรได้: จัดช่วงอ่านลงเวลาว่างจากตารางเรียน, ติ๊กและกด ง่าย/ยาก เพื่อปรับแผน, ทบทวนแบบเว้นระยะ,
บันทึกคะแนนสอบซ้อมพร้อมกราฟและระยะห่างจากเป้า, วันสำคัญ, เช็กลิสต์พอร์ตฟอลิโอ, สำรองและย้ายข้อมูล
ข้อมูลเก็บในเครื่องของผู้ใช้เท่านั้น

## เปิดใช้งานด้วย GitHub Pages
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repository `sea-to-university`
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save
3. แอปจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/sea-to-university/`

อัปเดตแอปเมื่อไร ให้เปลี่ยน `sea2uni-v1` ใน `sw.js` เป็นเลขใหม่

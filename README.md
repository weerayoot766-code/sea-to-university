# Sea To University
เส้นทางที่ฝ่ามรสุมจากทะเล จะผลักดันให้ฉันขึ้นฝั่งของมหาวิทยาลัย

แอปวางแผนอ่านหนังสือสำหรับนักเรียน ม.ต้น และ ม.ปลาย (PWA ไฟล์เดียว) โดย ปรุงยาเภสัช
- **ม.ต้น:** จัดตารางอ่านสอบในโรงเรียน + เตรียมสอบเข้า ม.4
- **ม.ปลาย:** จัดตารางอ่านสอบในโรงเรียน + เตรียม TCAS (TGAT · TPAT · A-Level)

## ทำอะไรได้บ้าง
- จัดช่วงอ่านลงเวลาว่างจากตารางเรียน (ตารางเรียนแยกสีประจำวัน เพิ่มคาบได้ทุกวันรวมเสาร์-อาทิตย์)
- ติ๊ก และกด ง่าย / พอได้ / ยาก เพื่อปรับแผน ทบทวนแบบเว้นระยะ
- เปิดแอปวันใหม่ ช่วงที่ไม่ได้ติ๊กจะถูกย้ายไปแผนข้างหน้าให้อัตโนมัติ
- ตัวจับเวลาตอนอ่าน ครบเวลาแล้วติ๊กให้เอง
- งานที่ต้องส่งครู: ใส่วันส่ง (คำนวณ “คาบหน้า” จากตารางเรียน) แอปหาเวลาทำให้ก่อนวันส่ง
- เตรียม TCAS: ปุ่มสนามสอบ TGAT / TPAT / A-Level พร้อมวันสอบ และปฏิทิน TCAS
- บันทึกคะแนนสอบซ้อมพร้อมกราฟ วันสำคัญ เช็กลิสต์พอร์ตฟอลิโอ
- สถิติอ่านต่อเนื่อง และเหรียญรางวัล 12 แบบ
- ส่งรายงานให้ผู้ปกครองเป็นลิงก์ทาง LINE (เตือนทุกวันอาทิตย์)
- เพิ่มแผน 7 วันลงปฏิทินมือถือ (.ics) ให้มือถือเตือนก่อนอ่าน 10 นาที
- แถบข่าวสาร (แก้ได้ที่ `news.json`) และนับถอยหลังวันสำคัญ TCAS อัตโนมัติ
- ธีมสี 8 แบบ, ติดตั้งลงหน้าจอโฮม (มีวิธีสำหรับ iPhone และเบราว์เซอร์ใน LINE)
- สำรองและย้ายข้อมูล พร้อมเตือนสำรองทุก 30 วัน
- ข้อมูลเก็บในเครื่องของผู้ใช้เท่านั้น ดูรายละเอียดในหน้านโยบายความเป็นส่วนตัวในแอป

## ไฟล์ในโปรเจกต์
| ไฟล์ | ใช้ทำอะไร |
|---|---|
| `index.html` | ตัวแอปทั้งหมด |
| `sw.js` | ให้แอปเปิดได้แม้ออฟไลน์ |
| `news.json` | ข่าวสารในแอป แก้ได้ทุกวัน |
| `manifest.webmanifest`, ไอคอน `.png` | ข้อมูลสำหรับติดตั้งลงหน้าจอโฮม |
| `.nojekyll` | ให้ GitHub Pages ใช้ไฟล์ตามที่เป็น |

## เปิดใช้งานด้วย GitHub Pages
1. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้น repository `sea-to-university`
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save
3. แอปจะอยู่ที่ `https://weerayoot766-code.github.io/sea-to-university/`

## กฎสำคัญเวลาแก้แอป
- **ห้ามเปลี่ยนชื่อ `sea2uni-v1`** ใน `index.html` เป็นที่เก็บข้อมูลของผู้ใช้ เปลี่ยนแล้วข้อมูลทุกคนจะหาย
- **แก้ `index.html` ทุกครั้ง ต้องเปลี่ยนเลขเวอร์ชัน 2 ที่ให้ตรงกัน**
  - `const CACHE = 'sea2uni-v20'` ใน `sw.js`
  - `const APP_VER='v20'` ใน `index.html` (เลขที่แสดงท้ายแอป)
- **แก้แค่ `news.json` ไม่ต้องเปลี่ยนเวอร์ชัน**

## ลงข่าวใน `news.json`
```json
{
  "id": "ชื่อเรียกข่าว-ห้ามซ้ำ",
  "text": "ข้อความข่าว",
  "level": "all",
  "start": "2026-11-20",
  "end": "2026-12-12",
  "hot": false,
  "link": "https://...",
  "linkText": "อ่านต่อ"
}
```
`level` = `all` / `lower` (ม.ต้น) / `upper` (ม.ปลาย) · ข่าวขึ้นเองตั้งแต่ `start` และหายเองหลัง `end` · `hot: true` = ป้ายด่วนสีส้ม

## ค่าที่ตั้งได้ใน `index.html`
| ค่า | ใช้ทำอะไร |
|---|---|
| `LINE_OA` | ลิงก์ LINE Official Account (ว่าง = ซ่อนปุ่ม) |
| `LINE_GROUP`, `LINE_GROUP_CODE` | ลิงก์และรหัส OpenChat ของผู้ใช้แอป (ว่าง = ซ่อนปุ่ม) |
| `CF_BEACON_TOKEN` | token ของ Cloudflare Web Analytics (ว่าง = ไม่นับสถิติ) |

## ดูสถิติใน Cloudflare Web Analytics
กรอง Path ให้เห็นเฉพาะแอปนี้ · `/sea-to-university/index.html` = เปิดจากแอปที่ติดตั้งลงหน้าจอโฮม (ตั้งไว้ใน `start_url` ของ `manifest.webmanifest`) · `/sea-to-university/` = เปิดผ่านเบราว์เซอร์หรือลิงก์
| `TCAS` | รายวิชาและวันสอบ TCAS ปีปัจจุบัน แก้ตรงนี้เมื่อขึ้นปีใหม่ |
